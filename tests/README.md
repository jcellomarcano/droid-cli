# tests/fixtures

## Capture

Each `.txt` fixture is the raw output of a single adb command (`adb shell dumpsys ...`,
`adb devices -l`, `adb logcat -v threadtime,year`, `cat /proc/net/tcp6`, ...), captured
once against a real or emulated device and saved verbatim into `tests/fixtures/raw/`.
`tests/fixtures/raw/` is never committed (see `.gitignore`) and never leaves the
machine that captured it; only the anonymized copies under `tests/fixtures/` ship
with the repository.

## Anonymization

Run:

```
python -m tests.anonymize
```

from the repository root. It reads every `*.txt` file under `tests/fixtures/raw/`,
replaces third-party package names, IPv4/IPv6 addresses (including their hex form
inside `/proc/net/{tcp,tcp6,udp,udp6}` dumps), MAC addresses, emails, and
device/serial/SSID identifiers with stable placeholders, and writes the result into
`tests/fixtures/`. The mapping is deterministic: the same raw input always produces
the same anonymized output, and the same real value always maps to the same
placeholder within a run.

`tests/test_fixtures_clean.py` re-checks every committed fixture listed in
`tests/fixtures/MANIFEST.txt` with an independent detector (`tests.anonymize.find_violations`)
that does not share tables with the anonymizer itself, so a rule the anonymizer forgot
to apply is still caught.

## MANIFEST.txt

`tests/fixtures/MANIFEST.txt` is generated by `tests.anonymize.write_manifest()`
every time `python -m tests.anonymize` runs — it is never hand-edited. One line
per fixture: `<name><TAB><sha256 of the anonymized content><TAB><line count><TAB><source>`.
`<source>` is read from the first line of `tests/fixtures/raw/SOURCES.txt` (falls
back to `unknown` when that file is absent); keeping `SOURCES.txt` accurate is the
responsibility of whoever captures the raw fixtures, not of the anonymizer.

`logcat_threadtime_year.txt` was truncated to 400 lines at capture time (not by
the anonymizer) to keep the fixture small; `netstats_uid_10001.txt` and `ps_A.txt`
were similarly trimmed to their first 40 raw lines before anonymizing.

## Fake adb in tests

`tests/test_logcat_stream.py` and `tests/test_adb_guard.py` write a small fake
`adb` bash script into `tmp_path` and mark themselves `@pytest.mark.allow_adb`
so the real-adb guard in `conftest.py` lets that fake binary run as a
subprocess. This needs `/bin/bash` and POSIX executable permissions (`chmod +x`),
so those tests only run on macOS/Linux, not on Windows.

## Provenance limitation

The anonymizer is a best-effort text substitution over known patterns (packages,
addresses, identifiers). It does not understand the semantic content of a dump, so
a fixture can still leak information that does not match any of its rules (for
example, a free-text log message that happens to mention a private hostname). Treat
`tests/fixtures/*.txt` as sanitized-for-known-patterns, not as a formal privacy
guarantee, and review new captures by hand before adding them to `raw/`.
